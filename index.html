How to Publish This App Live on GitHub Pages

1

Save the Code Locally

Save this complete single-file code as index.html on your computer.

2

Create a New GitHub Repository

Go to GitHub New Repository, name your repository (e.g., geoscout-app), and set it to Public.

3

Upload index.html

Click on "uploading an existing file" in your new repository, drag and drop your index.html file, and commit the changes.

4

Enable GitHub Pages

Go to your repository's Settings tab -> Click on Pages in the left sidebar. Under Build and deployment, select branch main (or master) and folder / (root), then click Save.

Your Live URL is Ready!

Within 1-2 minutes, GitHub will generate your live URL: https://yourusername.github.io/geoscout-app/
